# Support The Project

## Report issues

By far the easiest way to help make HomeRoll better is to use it and report issues and bugs. Found a bug? [Open an issue on GitHub][github-issue].

## Development

If you are a programmer or developer, take a look at HomeRoll's technology stack and consider fixing bugs or building new features. Contributions are always welcome — open a pull request against the `main` branch.

## Support upstream

HomeRoll is a fork of [Immich](https://github.com/immich-app/immich) — all credit for the underlying platform belongs to the Immich authors and contributors. If you'd like to support the ecosystem, consider contributing upstream.

[github-issue]: https://github.com/alzimerahmed/HomeRoll/issues/new/choose
